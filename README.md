# AIkanpan · AI 看盘助手

Windows 桌面版 A 股看盘工具：自选行情、K 线技术指标、排行榜、持仓盈亏、到价预警和可选的 AI 分析。数据默认保存在本机，不提供交易、云同步或自动更新。

## 安装与启动

适用于 Windows 10 / 11 64 位，无需安装 Node.js 或 npm。

1. 双击安装包 `release/aikanpan-0.1.0-setup.exe`。
2. 可按需选择安装目录；安装包支持中文和空格路径。
3. 安装完成后，双击桌面的 **AIkanpan** 图标。
4. 首次打开会显示可跳过的四步新手引导。默认使用“简洁”导航，常用功能是自选行情、K 线图、持仓和预警；其他功能在“更多”中，也可以切换到“完整”。

> 当前安装包未进行代码签名，Windows 可能提示“未知发布者”或 SmartScreen。请仅运行自己构建或来自可信来源的安装包。

## 日常使用

- **自选行情**：在顶部输入 6 位代码、名称或拼音，选择结果后会自动加入自选并打开 K 线。点击自选行也可切换股票。
- **K 线图**：切换日 K、周 K、月 K，按需打开 MA、BOLL、VOL、MACD、KDJ、RSI。
- **持仓**：填写代码、名称、买入均价、数量和日期，自动估算浮动盈亏；未计入手续费和税费。
- **预警**：设置价格或涨跌幅条件。单次预警触发后会自动停用，避免重复提醒。
- **AI 分析**：可选功能。没有 API Key 不影响行情、K 线、持仓和预警。
- **术语帮助**：在“帮助 → 术语帮助”中查看涨跌幅、换手率、成本价和技术指标说明。

### 关闭与退出

点击窗口右上角的关闭按钮只会隐藏到系统托盘，行情和预警会继续在后台监控。

- 双击托盘图标，或右键选择“打开主窗口”，可恢复窗口。
- 需要完全停止时，右键托盘图标并选择“真正退出”。
- 系统预警要求应用保持运行；电脑睡眠或完全退出后不会继续监控。

## 旧版数据迁移

安装版首次启动且尚无用户数据时，会询问是否导入旧项目的 `data` 文件夹。

- 可选择旧版 `data` 文件夹，或选择“暂不导入，直接开始”。
- 仅导入 `settings.json`、`watchlist.json`、`positions.json`、`alerts.json`。
- 导入前会校验 JSON；目标已存在的文件不会覆盖，旧文件不会被修改。
- 安装版数据位于 `app.getPath('userData')/data`，通常对应 `%APPDATA%\AIkanpan\data`。实际路径可在“更多 → 设置”中查看。
- 日志位于同一数据目录的 `logs/desktop.log`。
- 卸载应用不会删除上述用户数据，便于重装或升级后继续使用。

## AI 配置

在“更多 → 设置”中填写自己的 API Key、接口地址和模型名，可先测试连接再保存。支持 DeepSeek 及其他 OpenAI 兼容接口。

- API Key 保存在本机设置中，请勿分享或提交到代码仓库。
- AI 输出可能存在错误，仅供参考，不构成投资建议。

## 行情来源与限制

| 数据 | 来源 |
|---|---|
| 实时行情（自选、持仓、预警） | 腾讯财经 `qt.gtimg.cn` |
| K 线（日、周、月，前复权） | 腾讯财经 `web.ifzq.gtimg.cn` |
| 搜索联想 | 新浪财经 `suggest3.sinajs.cn` |
| 涨跌排行 | 新浪财经 `vip.stock.finance.sina.com.cn` |

后端统一代理并缓存请求，以减少重复访问。交易时段判断仅按北京时间工作日和开市时间估算，不处理法定节假日；休市时可能显示最近收盘数据。行情可能出现延迟、缺失或过期，应用会显示相应状态，请以交易所和券商数据为准。

## 开发者附录

需要修改源码或使用浏览器版时，才需要 Node.js 和 npm。

```bash
npm install
npm run dev          # Web 开发模式：后端 8787，前端 5173
```

构建生产 Web 版：

```bash
npm run build
npm start            # 访问 http://127.0.0.1:8787
```

构建并运行桌面开发版：

```bash
npm run build:desktop
npm run dev:desktop
```

生成 Windows x64 NSIS 安装包：

```bash
npm run dist:win     # 输出到 release/
```

检查前端、后端和 Electron 类型：

```bash
npm run typecheck
```

Web 版数据默认保存在项目 `data/`。也可以通过 `AIKANPAN_DATA_DIR` 指定其他目录；`.env.example` 提供了可选的 `DEEPSEEK_API_KEY` 配置示例。安装包不会打包项目 `data/`、`.env`、源码或开发缓存。
